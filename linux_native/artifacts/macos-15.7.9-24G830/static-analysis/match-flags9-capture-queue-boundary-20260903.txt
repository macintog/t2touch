Decision
--------

The first bounded research TUI discriminator sent flags 0x9 (unlock |
noBioLockout), matching the exact native success. The required no-finger gate
then returned status 22 before arming. Exact daemon and driver code explain the
rejection: bit 8 also requires noBioLockoutUserID at header offset 8 and an
exact 40-byte noBioLockoutAuthData value at offset 12. Loading and saving the
encrypted BioLockout record does not provide this authorization. The TUI was
returned to flags 0x1. Production fprint and the probe default never changed.
No flags-9 finger request is permitted without a separately recovered,
validated authorization producer and another no-finger gate.
